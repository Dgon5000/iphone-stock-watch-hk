# iPhone Stock Watch — Apple Store Hong Kong

Присылает уведомление в **Telegram**, когда iPhone 18 Pro Max появляется для **самовывоза (Pick up) в любом Apple Store Гонконга**.
## Что отслеживается

**iPhone 18 Pro Max 512GB, 1TB и 2TB во всех четырёх цветах** — 12 конфигураций. Артикулы гонконгские (`…ZA/A`), британские (`…QN/A`) в Гонконге не продаются. Цены — на 2 октября 2026.

| Память | Silver | Black | Glacier | Burgundy | Цена |
|---|---|---|---|---|---|
| 512GB | MJXU4ZA/A | MJXT4ZA/A | MJXW4ZA/A | MJXV4ZA/A | HK$13,299 |
| 1TB | MJXY4ZA/A | MJXX4ZA/A | MJY14ZA/A | MJY04ZA/A | HK$16,799 |
| 2TB | MJY34ZA/A | MJY24ZA/A | MJY54ZA/A | MJY44ZA/A | HK$21,999 |

Все 12 проверяются одним запросом во всех 6 магазинах Apple в Гонконге:

| Магазин | Район | Номер |
|---|---|---|
| Apple ifc mall | Central | R428 |
| Apple Causeway Bay | Causeway Bay | R409 |
| Apple Canton Road | Tsim Sha Tsui | R499 |
| Apple Festival Walk | Kowloon Tong | R485 |
| Apple apm Hong Kong | Kwun Tong | R673 |
| Apple New Town Plaza | Sha Tin | R610 |

Основной способ запуска — **VPS** (см. «Запуск на VPS»): проверка идёт круглосуточно с паузами **1, 2 и 3 минуты по кругу** (1 → 2 → 3 → 1 → …). Запасные варианты — GitHub Actions (ниже) и свой Mac.

Уведомление приходит при **любом изменении**: конфигурация появилась в наличии (хотя бы в одном магазине) или закончилась (её больше нет ни в одном). Пока ничего не меняется, бот молчит. Пример:

```
🍏 Apple Store Hong Kong

🟢 Появились · iPhone 18 Pro Max
🩶 512GB · Silver — 🛒 Оформить

🩶 1TB · Silver — 🛒 Оформить

🔴 Закончились · iPhone 18 Pro Max
🖤 2TB · Black
❤️ 2TB · Burgundy

🕐 Проверено: 02.10.2026 14:05 (HKT)
```

«🛒 Оформить» — ссылка прямо на эту конфигурацию на apple.com/hk; магазин для самовывоза выбирается при оформлении. Значок перед памятью показывает цвет: 🩶 Silver, 🖤 Black, 🩵 Glacier, ❤️ Burgundy. Варианты с разной памятью разделены пустой строкой, внизу — время проверки по Гонконгу (по часам Apple, поэтому оно точное, даже если часы сервера отстают).

Раз в 3 круга пауз (1 → 2 → 3, то есть раз в 18 минут) бот присылает **без звука** сводку: что сейчас в наличии (со ссылками) и чего нет — одной строкой. Так видно, что проверка работает, даже когда ничего не меняется. Прислать сводку сразу: командой /iphone в боте (см. ниже) или с Mac — `ssh root@IP "bash ~/iPhone_Checker/vps_install.sh status"` (здесь и ниже `IP` — адрес вашего сервера). Изменить паузы и частоту сводок: `ssh root@IP "SCHEDULE=1,2,3 STATUS_ROUNDS=3 bash ~/iPhone_Checker/vps_install.sh"` (`STATUS_ROUNDS=0` — без сводок).

### Журнал наличия и отчёт

Каждая проверка записывается в `/opt/iphone-stock-watch-hk/stock_history.jsonl` на сервере: время по Гонконгу и какие конфигурации в каких магазинах были в наличии. Проще всего посмотреть отчёт командой **/report** в боте: он пришлёт, когда что появлялось, сколько держалось, в какие часы и в каких магазинах чаще, и файл-таблицу со всеми появлениями. То же самое с сервера:

```bash
ssh root@IP "bash ~/iPhone_Checker/vps_install.sh report"
```

С таблицей для Excel/Numbers (`;`-разделённый CSV, каждое появление — строка) и копированием на Mac:

```bash
ssh root@IP "bash ~/iPhone_Checker/vps_install.sh report --csv /root/stock_intervals.csv" && scp root@IP:/root/stock_intervals.csv ~/iPhone_Checker/
```

Отсутствие короче 5 минут отчёт считает «миганием» Apple и не делит появление на два. Журнал начинается с 2 октября 2026: утро восстановлено по истории GitHub, дальше — по логу сервера.

### Команда /iphone

Отправьте боту **/iphone** (команда есть в меню бота, кнопка «/») — он сразу проверит Apple и пришлёт ту же сводку: что в наличии и чего нет. На паузы 1 → 2 → 3 и на уведомления об изменениях это не влияет: команду обрабатывает отдельная служба `iphone-stock-watch-hk-bot`. Бот отвечает только чатам из `TELEGRAM_CHAT_ID`; повторные /iphone в течение 20 секунд получают тот же ответ без нового запроса к Apple. Лог: `journalctl -u iphone-stock-watch-hk-bot -f`.

Пока бот работает на сервере, `telegram_setup.py` не сможет прочитать сообщения боту (Telegram отдаёт их только одному читателю): при повторной настройке остановите бота командой `systemctl stop iphone-stock-watch-hk-bot`, а потом запустите снова (`start`).

Пока Apple выкладывает партию, его ответы несколько минут «мигают»: есть → нет → есть. Поэтому «закончилась» бот сообщает только после повторной проверки через 20 секунд: если конфигурация вернулась, это было «мигание», и сообщения не будет. О появлении бот пишет сразу.

## 1. Создайте Telegram-бота

1. В Telegram откройте **@BotFather**, отправьте `/newbot`, придумайте имя и username (должен заканчиваться на `bot`). BotFather пришлёт токен вида `123456789:AAH…`.
2. Откройте своего бота по ссылке от BotFather и нажмите **Start** — без этого бот не сможет вам писать.
3. Узнайте chat ID:

   ```bash
   python3 telegram_setup.py
   ```

   Скрипт спросит токен, найдёт ваш чат и пришлёт в него подтверждение. Символы при вводе не отображаются: вставьте токен один раз (`Cmd + V`) и сразу нажмите Enter. Нужен только Python 3, сторонние библиотеки не нужны.

   Без скрипта: откройте в браузере `https://api.telegram.org/bot<ТОКЕН>/getUpdates` и найдите `"chat":{"id":123456789`.

Чтобы уведомления приходили в группу, добавьте туда бота, напишите в группе любое сообщение и снова запустите `telegram_setup.py` — у группы chat ID отрицательный. Несколько получателей — через запятую.

Токен бота — это пароль: не коммитьте его в репозиторий.

## 2. Создайте репозиторий

Рекомендуется **публичный** репозиторий: в публичных репозиториях стандартные GitHub Actions бесплатны и без лимита минут. В приватном бесплатных 2000 минут в месяц хватит примерно на неделю. Токен в файлы не кладите — только в секреты (шаг 3).

Создайте на github.com пустой репозиторий (без README и .gitignore) и загрузите в него все файлы этой папки, включая `.github/workflows/`.

Через терминал:

```bash
cd ~/iPhone_Checker
git init -b main
git add .
git commit -m "Apple Store Hong Kong stock watch"
git remote add origin https://github.com/<ваш-логин>/<имя-репозитория>.git
git push -u origin main
```

Или через сайт: **Add file → Upload files** и перетащите содержимое папки. Скрытую папку `.github` Finder перетащить не даст, поэтому перед загрузкой переименуйте её в `github` (скрытые файлы показывает `Cmd + Shift + .`). После загрузки создайте на GitHub файлы с правильным путём: **Add file → Create new file**, имя наберите на клавиатуре — `.github/workflows/stock-watch.yml`, вставьте содержимое одноимённого файла из `github/workflows/` (на его странице есть кнопка **Copy raw file**) и нажмите **Commit changes**; то же для `test-telegram.yml` и `watchdog.yml`. Без папки `.github/workflows` с точкой ничего запускаться не будет.

## 3. Добавьте секреты GitHub Actions

В репозитории: **Settings → Secrets and variables → Actions → Secrets → New repository secret**

- `TELEGRAM_BOT_TOKEN` — токен бота от @BotFather
- `TELEGRAM_CHAT_ID` — ваш chat ID из шага 1 (несколько — через запятую)

## 4. Проверьте

1. **Actions → Test Telegram Alert → Run workflow.** В Telegram придёт тестовое сообщение с текущим наличием всех 12 конфигураций.
2. **Actions → iPhone Stock Watch (Apple Store Hong Kong) → Run workflow.** В логе шага «Watch Apple Store Hong Kong pickup stock» появятся строки вида:

   ```
   [2026-10-02 06:50:41 HKT] 6 stores × 12 models checked — no pickup stock
   ```

Если товара нет, запуск завершается без сообщения.

Такая строка будет появляться каждые 5 минут, сам запуск при этом остаётся «в работе» почти 6 часов — так и задумано. Нажать **Run workflow** нужно один раз, дальше проверка работает сама.

GitHub сам пишет на почту об упавших запусках. Если эти письма не нужны, на github.com/settings/notifications в разделе **System → Actions** снимите **Email**: о сбоях и так сообщит Telegram (см. ниже).

## Если проверка сломалась

Если проверки не проходят дольше 30 минут подряд (Apple блокирует запросы, изменил API или в `PART_NUMBERS` неверный артикул), бот один раз пришлёт «⚠️ Проверка наличия … не работает» со ссылкой на лог запуска. Когда всё восстановится, придёт «✅ … снова работает». Короткие сбои не сообщаются.

Если не приходит даже тестовое сообщение, ошибка видна в логе Test Telegram Alert:

| Ошибка | Что сделать |
|---|---|
| `HTTP 401 Unauthorized` | Неверный или отозванный `TELEGRAM_BOT_TOKEN` |
| `HTTP 404 Not Found` или `TELEGRAM_BOT_TOKEN is malformed` | Токен вставлен с лишними или недостающими символами — скопируйте его заново |
| `Bad Request: chat not found` | Неверный `TELEGRAM_CHAT_ID` |
| `Forbidden: bot can't initiate conversation with a user` | Откройте бота и нажмите Start |

## Другие модели и частота проверок

Всё настраивается без правки кода: **Settings → Secrets and variables → Actions → Variables → New repository variable**

| Переменная | По умолчанию | Что делает |
|---|---|---|
| `PART_NUMBERS` | 12 конфигураций выше | Свой список артикулов через запятую, например `MJXU4ZA/A,MJXT4ZA/A`. Apple отдаёт не больше 20 артикулов за запрос; если указать больше, скрипт сам разобьёт их на несколько запросов. |
| `CHECK_INTERVAL_SECONDS` | `300` | Пауза между проверками в секундах, не меньше 30. Например, `120` — проверка раз в 2 минуты. |

Переменные читаются при старте запуска. Чтобы изменения подействовали сразу: **Actions → iPhone Stock Watch (Apple Store Hong Kong)** → откройте текущий запуск → **Cancel workflow run** → затем **Run workflow**. Изменения файлов (например, новая версия `check_stock.py`) подхватываются без перезапуска — со следующей проверки.

## Как остановить

Когда iPhone куплен: **Actions → iPhone Stock Watch (Apple Store Hong Kong) → … (справа вверху) → Disable workflow**, затем откройте текущий запуск и нажмите **Cancel workflow run**. «Сторож» отключённую проверку не запускает; его можно отключить так же. Включить всё обратно — **Enable workflow** и **Run workflow**.

## Как бот помнит, что уже сообщал

`stock_state.json` хранит, какие конфигурации были в наличии при последней проверке. Сообщение приходит, только когда этот список меняется. Если отправить сообщение не удалось, список не обновляется, и сообщение повторится на следующей проверке.

## Запуск на своём Mac

Вместо VPS проверку можно запускать на Mac — с теми же паузами 1, 2, 3 минуты, в том числе после перезагрузки и входа в систему. Но только пока Mac не спит: с закрытой крышкой MacBook засыпает, и проверки продолжатся после пробуждения.

1. Сохраните настройки Telegram на этом Mac — на вопрос «Сохранить токен и chat ID…» нажмите Enter:

   ```bash
   python3 telegram_setup.py
   ```

   Они сохранятся в `~/.config/iphone-stock-watch-hk/config.env` — вне папки проекта, чтобы токен случайно не попал на GitHub.

2. Включите проверку — в Telegram придёт тестовое сообщение:

   ```bash
   bash macos.sh install
   ```

macOS может показать уведомление о новом фоновом объекте `python3` — это и есть проверка. Другие команды: `bash macos.sh status` (работает ли и последние проверки), `bash macos.sh log` (лог в реальном времени), `bash macos.sh uninstall` (выключить). Другие паузы, например 5, 3 и 4 минуты по очереди: `bash macos.sh install 5,3,4`.

Разовая проверка без отправки сообщений: `python3 check_stock.py --dry-run`.

## Запуск на VPS

Самый надёжный вариант, работает круглосуточно: любой Linux-сервер с systemd (Ubuntu 22.04/24.04, Debian 12), подойдёт самый дешёвый тариф. С Mac скопируйте папку на сервер и запустите установщик (вместо `IP` — адрес сервера):

```bash
scp -r ~/iPhone_Checker root@IP:~/
```

```bash
ssh -t root@IP "bash ~/iPhone_Checker/vps_install.sh"
```

Установщик спросит токен бота (ввод скрыт) и chat ID, пришлёт тестовое сообщение и запустит службу, которая проверяет постоянно с паузами 1, 2, 3 минуты по кругу (сводка раз в 3 круга) и сама запускается после перезагрузки сервера или сбоя. Другие паузы и частота сводок: `SCHEDULE=5,3,4 STATUS_ROUNDS=1 bash ~/iPhone_Checker/vps_install.sh`. Если вы входите не под `root`, запускайте через `sudo bash …`.

Лог: `journalctl -u iphone-stock-watch-hk -f`. Обновить скрипт: снова скопируйте папку и запустите установщик — настройки и память бота сохранятся. Удалить: `sudo bash ~/iPhone_Checker/vps_install.sh uninstall`.

Apple может блокировать адреса некоторых хостингов. Тогда через 30 минут бот пришлёт «⚠️ Проверка наличия … не работает».

## Только один способ одновременно

У каждой копии — GitHub, Mac, VPS — своя память о том, что уже присылалось. Если запустить две сразу, сообщения будут приходить дважды. Включив проверку на Mac или VPS, остановите её на GitHub (см. «Как остановить»).

## Чем отличается от оригинала

- Уведомления в Telegram вместо почты, плюс сообщения о сбоях проверки.
- apple.com/hk вместо apple.com/uk и артикулы `…ZA/A`. Почтовых индексов в Гонконге нет: на запрос с районом `Central` Apple возвращает все 6 магазинов.
- 12 конфигураций одним запросом вместо одной; название модели берётся из ответа Apple.
- Проверка ровно каждые 5 минут без перерывов. Расписание «каждые 5 минут» GitHub на практике запускает раз в 15–20 минут (это видно по истории коммитов оригинала), а для нового workflow первый запуск может не случиться и за полчаса.
- Исправлена проверка `storeSelectionEnabled`: в ответе Apple это поле лежит в `messageTypes.regular`, а оригинал искал его уровнем выше и фактически смотрел только на `pickupDisplay`.
- Состояние коммитится только при изменениях, а не каждые 5 минут.
- Неверный артикул (например, британский) — явная ошибка, а не тихое «нет в наличии».

## Ограничения

- API самовывоза Apple недокументирован и может измениться. Скрипт делает только публичные read-only запросы, как страница магазина, и не обходит CAPTCHA, авторизацию, ограничения частоты или защиту от ботов.
- Проверка постоянно занимает один сервер GitHub Actions. Для публичного репозитория это бесплатно, но это постоянная нагрузка — после покупки остановите проверку (см. «Как остановить»).
- Если у GitHub сбой и цепочка запусков прервётся, «Сторож» перезапустит её в течение часа; его собственное расписание GitHub тоже может немного задерживать.
- В публичном репозитории GitHub отключает расписание «Сторожа» после 60 дней без активности. Включить снова: **Actions → Stock Watch Watchdog → Enable workflow**.
- Наличие меняется быстро. Перед поездкой проверьте магазин и время выдачи на сайте Apple.
